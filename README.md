# Full Stack Task Manager

A full-stack task management application built using React, Express.js, and JSON file persistence.

## Features

* Add new tasks
* Edit existing tasks
* Delete tasks with confirmation
* Mark tasks as complete/incomplete
* Filter tasks (All, Active, Completed)
* Search tasks by title
* Due date support
* Overdue task highlighting
* Dashboard statistics
* Loading and error states
* Persistent storage using JSON file storage

## Tech Stack

### Frontend

* React
* Vite
* Axios
* React Icons
* CSS

### Backend

* Node.js
* Express.js
* CORS
* File System (JSON Persistence)

## Project Structure

client/ - React Frontend
server/ - Express Backend
server/data/tasks.json - Persistent Task Storage

## Installation

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm start
```
